# Format: tutorial

Teaches one task, start to finish, so the viewer can do it themselves.

- **Sources:** the docs, manual or README section for the task; then walk the task yourself in
  the demo and note every click, field and result. The walk is the truth when the docs differ;
  tell the user about the gap.
- **Brief defaults:** audience is a new user who has the app open; goal is "done the task once";
  length 1-4 min, about 15-30 s per step; tone calm and patient (`[warmly]`, `[softly]`,
  `[confident]`, few `[upbeat]`); 16:9; captions on, one per step.
- **Beats:** the result first (what you'll have at the end), then each step in order, then
  a check that it worked.
- **Shot structure:** title card naming the task, a "here's what you'll build" shot of the end
  state, one shot per step (ring the exact control, then the result it produced), a recap card
  listing the steps.
- **Script:** second person, present tense, one action per sentence ("Click New project. Give it
  a name."). Say the control's exact on-screen label. Never skip a step a beginner needs.
- **Capture:** use `setup` steps (`click`, `fill`, `press`) to show each step's before and after
  as two callouts; mock slow or external results instead of waiting for them.
