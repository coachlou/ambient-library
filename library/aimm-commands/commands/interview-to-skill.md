# The Interview-to-Skill Builder

Turn a one-off document or deliverable into a repeatable, self-improving skill by having Claude interview you first, then codify the whole process at the end. From the May 28, 2026 AIMM session, Lou's technique for turning Dirk's quarterly board letter (and any high-stakes recurring deliverable) into a compounding asset instead of a fresh panic every time.

---

$ARGUMENTS

If no deliverable was provided above, ask me what I'm trying to produce before proceeding.

Before you write anything, interview me. Ask the questions I need to answer to do this well, one or a few at a time, not all at once. Cover substance, audience, tone, and any domain-specific concerns (legal, compliance, brand, technical accuracy). Push back where my answers are thin or inconsistent.

When I tell you I'm happy with where we've landed, do two things:
1. Produce the final deliverable.
2. Review everything we did in this conversation and turn the whole process into a reusable skill, so I can run it again next time without starting from scratch.

Going forward: every time I use this skill and correct something, learn from the correction and update the skill so it gets smarter on each run.
