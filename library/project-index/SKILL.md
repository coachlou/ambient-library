---
name: project-index
description: Use when the user wants an overview, inventory, or status review of the projects/folders in a directory — "what have I been working on", "index my projects folder", "give me a status of everything in this directory", "catalog these folders". Scans one or more directories (no recursion), infers a one-line description and status per folder, and produces a markdown index plus a searchable HTML page.
---

Read `instructions.md` in this skill's directory and follow it.

Path note: this skill also ships inside the `ambient` library plugin, so its
instructions may reference files as `${CLAUDE_PLUGIN_ROOT}/library/project-index/<file>`.
When installed standalone, resolve those to `<file>` in this directory.
